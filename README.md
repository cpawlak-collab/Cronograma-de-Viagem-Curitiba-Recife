# Cronograma-de-Viagem-Curitiba-Recife
O planejamento financeiro para a viagem de Curitiba a Recife totaliza R$ 2.950,00. As despesas dividem-se em: passagem de avião a R$ 1.300,00 (1 unidade); hospedagem a R$ 1.000,00 (5 diárias a R$ 200,00); alimentação a R$ 500,00 (5 dias a R$ 100,00); e transporte a R$ 150,00 (3 utilizações a R$ 50,00).
